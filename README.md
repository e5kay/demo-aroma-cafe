# Καφέ «Aroma»

Premium, μοντέρνα ιστοσελίδα για το all-day café-bar «Aroma» στον Πειραιά.

- Είδος: All-day Café-Bar
- Slogan: «Καφές, brunch & cocktails στον Πειραιά.»
- Διεύθυνση: Λεωφόρος Δημοκρατίας 45, Πειραιάς 185 34
- Τηλέφωνο: 210 1234567
- Ωράριο: Τρίτη – Κυριακή, 12:00 – 00:30 (Δευτέρα κλειστά)
- Παροχές: Specialty καφές, brunch, signature cocktails, Wi-Fi, take away & delivery

## Ενότητες σελίδας

1. Sticky πλοήγηση: λογότυπο, σύνδεσμοι (Μενού, Ο χώρος, Κριτικές, Επικοινωνία) και κουμπί κλήσης.
2. Hero: βαθμολογία Google, κύριο μήνυμα και CTAs (Κλήση, Μενού, Οδηγίες).
3. Highlights: specialty καφές, brunch, cocktails, take away & delivery.
4. Επιλεγμένα προϊόντα: Flat White, Avocado Toast, Pancakes με μέλι, Espresso Martini.
5. Μενού με καρτέλες: Καφές, Brunch, Σνακ & Σαλάτες, Cocktails & Ποτά.
6. «Ο χώρος»: φωτογραφίες σε οριζόντιο scroll.
7. Κριτικές πελατών (Google).
8. Τοποθεσία & ωράριο με χάρτη Google Maps και click-to-call.

Ο σχεδιασμός χρησιμοποιεί ανθρακί φόντο, χρυσές λεπτομέρειες και smooth scroll animations (Framer Motion).

## Τεχνολογίες

- Vite + React 19 + TypeScript
- TanStack Router / TanStack Start
- Tailwind CSS v4 (τα design tokens ορίζονται στο `src/styles.css`)
- Framer Motion, lucide-react

## Ανάπτυξη

```sh
npm i
npm run dev
```
